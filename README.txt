# GASC Avinashi - Tech Events 2026

A responsive event website for:
Government Arts and Science College, Avinashi
Department of Computer Science

Events:
- Connection
- Poster Design
- Paper Presentation
- AI Prompt Engineering

Coordinators:
- Iswarya
- Tamilselvi

## Run
Open `index.html` in any modern browser.

## Customize
- Replace `college-logo.png` with a higher-resolution logo if available.
- Edit event rules/details in `index.html` and `script.js`.
- The registration form is currently a front-end demo. Connect it to Google Forms, Firebase, or another backend to store submissions.
